TÍTULO: [BUG] Autocadastro responde 401 depois do controle de acesso
ID PROVISÓRIO: BUG-01
CHAVE NO JIRA: a confirmar
RELEASE: R1 - Acesso e Cadastro
SPRINT: 1
US RELACIONADA: SCRUM-39 / US-04 - Autocadastro do paciente com consentimento
CASOS RELACIONADOS: CT-US04-01, CT-US04-02, CT-US04-03
SEVERIDADE: Alta
PRIORIDADE: Alta
RESPONSÁVEL: Maria Eduarda da Nóbrega
REPORTADO POR: Mirelle Casimiro Silvino (QA)
SITUAÇÃO: Corrigido e retestado

----------------------------------------------------------------
DESCRIÇÃO
----------------------------------------------------------------
Depois da integração da US02 na develop, o POST /pacientes/autocadastro passou a exigir autenticação e respondeu 401. Como o paciente ainda não está autenticado no fluxo de autocadastro, não conseguia concluir o cadastro.

----------------------------------------------------------------
AMBIENTE
----------------------------------------------------------------
Ambiente: local com PostgreSQL 16 e CI do GitHub Actions com H2
Navegador / versão: não se aplica
Sistema operacional: Windows
Versão / commit / branch: develop, commit b2632e6, merge do PR #13 (CI #34)
US de origem: SCRUM-39, feature/SCRUM-39-autocadastro-paciente
Versão corrigida: develop, commit 4b1bf1c, CI #39

----------------------------------------------------------------
PASSOS PARA REPRODUZIR
----------------------------------------------------------------
1. Atualizar a develop para o commit b2632e6.
2. Executar o mvn verify ou subir a aplicação.
3. Chamar POST /pacientes/autocadastro sem token, com dados fictícios e aceite do termo LGPD marcado.
4. Observar a resposta HTTP.

----------------------------------------------------------------
RESULTADO ESPERADO
----------------------------------------------------------------
CT-US04-01: a conta é criada e o aceite é registrado com data e hora.
CT-US04-02: sem consentimento, o cadastro não é concluído e a finalidade do uso dos dados é exibida.
CT-US04-03: um CPF com dígito verificador inválido recebe a mensagem "CPF inválido".

----------------------------------------------------------------
RESULTADO OBTIDO
----------------------------------------------------------------
A rota respondeu 401 em vez de processar o autocadastro. CT-US04-01, CT-US04-02 e CT-US04-03 falharam no back-end da develop durante o CI #34.

----------------------------------------------------------------
CORREÇÃO
----------------------------------------------------------------
O POST /pacientes/autocadastro foi liberado no SecurityConfig, mantendo protegidas as demais rotas.

----------------------------------------------------------------
RETESTE
----------------------------------------------------------------

Run: CI #39, develop, commit 4b1bf1c
Resultado: verde
Reteste: CT-US04-01, CT-US04-02 e CT-US04-03 aprovados
Situação: corrigido e retestado

EVIDÊNCIAS
